**Çalıştırılan testler ve sınırlar**

- Dalın unittest keşfi: **67 test; 64 geçti, 1 başarısız, 1 hata, 1 atlandı.** Üretim UNC yolları inceleme koşumunda engellendi; ağ erişimi sonucu gibi yorumlanmamalı.
- Başarısız `test_cache_writes_short_layout_and_reads_legacy`: Windows’ta `write_text` LF’yi CRLF’ye çevirdiğinden testin beklediği 8 bayt fiilen 10 bayt oluyor. Boyut parametresi uyuşmuyor. Bu, test verisi/platform uyumsuzluğu; tek başına uygulamadaki legacy okumanın bozuk olduğunu kanıtlamaz.
- Hata `test_narrower_extract_keeps_previous_document`: testin geçici SQLite dosyası temizlenirken WinError 32 (dosya açık/kilitli) oluştu. Hata cleanup aşamasında; geçmiş koruma kuralı assert’i olarak raporlanmamalı. Bağlantıların açıkça kapatılması gerekir.
- Atlanan `test_exe_mentions_full_purge`: kök EXE ikilisi yerel inceleme kopyasına indirilmedi. Kurucu çalıştırılmadı; temiz kurulum ve kullanıcı ortamı testi yapılmadı.
- Python syntax/AST ve app.js Node syntax kontrolü geçti. Kendi ek yerel senaryolarım yukarıdaki ilk dört bulguyu yeniden üretti. Ayrıca proje etiketi fonksiyonu izole JavaScript bağlamında çalıştırıldı: depo seçili/seçili değil durumlarının ikisinde de yalnız “Proje A” döndü.
- Manifest release_id ile config release_id eşleşiyor. GitHub ağaç metadatasındaki dağıtım ZIP boyutu manifestteki **56.362.293 bayt** ile eşleşiyor. ZIP’in gerçek SHA256’sı/içeriği indirilerek doğrulanmadı; build/source/binary tam eşleşmesi teyit edilmiş sayılmaz.
- Çoklu PC’de eşzamanlı merkezi yayın, gerçek Windows AD/panel yetkisi ve SMB/NTFS izinleri, offline/online geçişi ve uzun UNC yolları ayrıca canlı ortamda sınanmalı. Merkezi yayın kilitleri process-içi; çoklu istemci yarışları bu testlerin kanıtladığı kapsamda değil.

**Düzeltme sırası**

1. Satır kimliklerinde kalem/mükerrer veri kaybını giderme.
2. Satır eşdeğer güncellemede indeks/snapshot imzalarını tutarlı yönetme.
3. Güvenilir yönetici yetkilendirmesi ve sorumluluk kaydını tamamlama.
4. Gerçek satır delta indeksi ve açık iş boyunca veri sürümünü sabitleme.
